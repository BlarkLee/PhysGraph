# 候选路线对比（执行版）

更新时间：2026-04-11

## 1. 方案对比

## 方案 A：保守（第一阶段主线）
- 核心做法：
  - 保留现有图结构与 object token 数量；
  - 用 `pt_pos/pt_flow` 替代 object pose 主奖励；
  - 点对特征压缩后回填 object token。
- 优点：
  - 改动最小，最容易拿到稳定训练结果；
  - 最适合做 A0-A3 公平对照。
- 风险：
  - 局部接触传播表达能力有限；
  - 新颖性偏工程迁移。

## 方案 B：中间（A 后升级）
- 核心做法：
  - 少量 anchor token（8/16）；
  - fingertip 与 nearby anchor 建动态边；
  - 增量扩展 bias 映射，不做彻底重构。
- 优点：
  - 更符合 PhysGraph 的局部关系建模优势；
  - 新颖性与性能上限更高。
- 风险：
  - 训练稳定性下降，调参成本上升。

## 方案 C：激进（后置探索）
- 核心做法：
  - 全锚点图 + 全量接触几何/力约束；
  - 端到端高复杂度奖励组合。
- 优点：
  - 理论表达能力与研究新颖性最高。
- 风险：
  - 实现复杂、失败概率高，不适合第一阶段直接投入。

## 2. 横向打分（5 分制）
| 方案 | 工程可行性 | 训练稳定性 | 表达上限 | 新颖性 | 推荐时机 |
|---|---:|---:|---:|---:|---|
| A | 5 | 4 | 3 | 2.5 | 立即 |
| B | 3.5 | 3 | 4.5 | 4 | A 通过后 |
| C | 2 | 2 | 5 | 5 | B 稳定后 |

## 3. 与里程碑映射
- M0-M2：执行方案 A（对应 `A0/A1/A2`）。
- M3：完成 `A3` 并做闸门判断。
- 仅当 `A2/A3` 稳定优于 `A0`：开启方案 B。
- 方案 C：不纳入第一阶段计划。

## 4. 结论
- 推荐：先 A，预留 B 接口，C 后置。
- 原因：当前项目最需要先验证“点表征替代 pose”这一核心假设，A 的性价比最高。
