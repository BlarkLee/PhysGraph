## 1. 项目目标
- 将 PhysGraph 第一阶段聚焦到 `OakInk + 点轨迹对象表征`。
- 保留手部 imitation 主干，优先验证点表征是否稳定优于 pose 基线。
- 仅单手先行，双手与全锚点结构升级后置。

## 1.1 当前阶段目标（补充）
- 在 OakInk 短序列上跑通并稳定复现 `A0/A1/A2/A3`。
- 用统一数据域得出可靠门禁结论：`A2/A3` 是否稳定优于 `A0`。
- 控制变量优先级高于扩展覆盖面，不再引入跨数据集干扰项。

## 2. 当前决策
- 主方案：`A 方案`（单 object token + 点轨迹奖励）。
- 升级条件：仅当 `A2/A3` 稳定优于 `A0`，进入 `B 方案`（anchor token 扩展）。
- 不建议直接 `C 方案`（高新颖性但高失败风险）。

## 4. 成功判据（第一阶段）
- 训练稳定：无早期持续崩溃，异常率可控。
- 效果可比：A1/A2 不低于 A0，且点误差趋势下降。
- 决策可落地：A2/A3 相对 A0 的升级结论明确（进 B 或继续优化 A）。
